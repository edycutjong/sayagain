CH-01 · how the channel hears it today

Two lines. Nobody flags them.

no flag · no card · the crew walks to XV-208

In the registry the demo runs on, XV-203 is on line B at the press station; XV-208 is on line A, in clarification.

This is the read-back as the channel hears it. Both lines sound routine. The read-back exists so the operator catches the wrong digit, and when the operator misses it too, nothing else on the channel checks it.

Aviation has studied this: controllers catch only part of the wrong read-backs. On plant radio there is no published rate at all, and isolation miscommunication has killed people. The safety literature calls this check three-way communication.

The supervisor queue · stored shift replayed

The supervisor gets the one wrong word.

  1. 1the read-back word that differs
  2. 2the diff, checked against the registry
  3. 3a human confirms or dismisses
This is the real queue, replaying a stored shift. Red appears only on the read-back word the order did not have. Nothing is sent to the plant: the card leaves the queue only through a supervisor's decision, and every card lists the receipts of the model calls behind it.

One model job · everything else is code

The model points. Code decides.

The model has one job: copy out the words that carry the action, the tag and the line. Plain code checks those words are really in the transcript, that every safety word is accounted for, and that the tag exists in the plant registry. A pure function returns the verdict; the model never writes it.

Radio loggers already record, transcribe and spot keywords. Among the vendors we checked, none documents comparing an instruction with its read-back. Automatic read-back checking exists in air-traffic research; IntelliPERMIT checks radioed codes, which needs a procedure change. SayAgain checks natural speech against the plant's own registry.
