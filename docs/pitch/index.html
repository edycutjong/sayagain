No rate

published for plant radio

In aviation, tower controllers catch 63 percent of pilots' wrong read-backs and approach controllers half; the rest go through. Nobody has published that number for plant radio, so a pilot's first job is to measure it. And a wrong valve state is not abstract: at Goodyear in 2008 an isolation valve left closed after maintenance, then a blocked relief path, led to a heat-exchanger rupture that killed one worker and injured six, according to the Chemical Safety Board.

This is one real exchange end to end. The model has one job, on the AMD Token Factory: copy out the words that carry the action, the tag and the line. Each call leaves a receipt with the host, the model served, the request id and the cost; speech-to-text has not run on a recording yet. Plain code checks those words are really in the transcript, that every safety word is accounted for, and that the tag exists in the plant registry. A pure function returns the verdict; the model never writes it.

On written words, the regex rung meets the rule too.

The rule was pre-registered before the first model call: the smallest rung with no wrong read-back passed and a false-alarm load the shift can absorb. No rung passed a wrong read-back; the LLM-judge baseline did, twice. Gemma is the only model rung inside the budget, in its re-audit: the first pass left 45 cards not audited after gateway errors, and Qwen's first pass left 3. With 48 correct read-backs the interval on Gemma's two false alarms is wide: the 95 percent Wilson interval runs from 1.15 to 13.98 percent. On clean written words the plain regex meets the rule too; the recordings will show whether that survives real speech.

Radio loggers already record, transcribe and spot keywords. Among the vendors we checked, none documents comparing an instruction with its read-back. Automatic read-back checking exists in air-traffic research; IntelliPERMIT checks radioed codes, which needs a procedure change. SayAgain checks natural speech against the plant's own registry.
